# 🔐 Cifra de Vigenère em Python

Projeto desenvolvido em Python com o objetivo de demonstrar o funcionamento da cifra de Vigenère, uma técnica clássica de criptografia baseada em substituição polialfabética.

---

## 👩‍💻 Sobre o Projeto

Este projeto permite criptografar e descriptografar mensagens utilizando uma chave personalizada. O programa funciona via terminal e aplica deslocamentos nas letras com base na posição alfabética da chave informada pelo usuário.

O desenvolvimento do projeto teve como foco a prática de lógica de programação, manipulação de strings e conceitos básicos de criptografia.

---

## 🚀 Funcionalidades

✅ Criptografar mensagens
✅ Descriptografar mensagens
✅ Utilização de chave personalizada
✅ Interface simples no terminal
✅ Tratamento de letras maiúsculas e minúsculas

## 🔍 Como Funciona

A cifra de Vigenère utiliza uma chave para gerar deslocamentos no alfabeto.

Exemplo:

* A = 1
* B = 2
* C = 3

Cada letra da mensagem é deslocada de acordo com os valores da chave.
